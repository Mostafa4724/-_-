# منصة مستر أحمد — الإصدار الاحترافي

نسخة معاد بناؤها من المشروع المرفق، وليست مجرد تعديل ألوان. تحتوي على:
- واجهة عربية RTL للطلاب ولوحة إدارة للمدرّس.
- تسجيل حسابات الطلاب وتسجيل الدخول.
- إعداد أول حساب مدير من شاشة آمنة لمرة واحدة.
- إدارة الدروس والواجبات والامتحانات من لوحة الإدارة.
- امتحانات اختيار من متعدد مع تصحيح تلقائي وحفظ النتيجة.
- إرسال الواجبات ومراجعة التسليمات.
- إدارة حسابات الطلاب وتفعيلها أو إيقافها.
- إشعارات تصل إلى مساحة الطالب.
- قاعدة بيانات SQLite فعلية تحفظ البيانات بعد إغلاق السيرفر.
- جلسات دخول في Cookie من نوع HttpOnly، وتجزئة كلمات المرور، وتحديد محاولات تسجيل الدخول.

## المتطلبات
- Node.js 20 أو أحدث.
- اتصال إنترنت في أول مرة لتثبيت الحزم.

## التثبيت على Windows PowerShell

افتح PowerShell داخل مجلد المشروع، ثم نفّذ:

```powershell
npm install
npm start
```

إذا كان `npm` غير معروف في PowerShell بينما Node مثبت في `D:\\node.exe`، استخدم ملف npm الموجود في `D:\\`:

```powershell
& "D:\\npm.cmd" install
& "D:\\node.exe" server.js
```

ثم افتح:
- الطالب: http://localhost:3000
- لوحة الإدارة: http://localhost:3000/admin

## أول تشغيل
1. افتح http://localhost:3000.
2. ستظهر شاشة إعداد حساب المدير لأن قاعدة البيانات جديدة.
3. أنشئ حساب المدرّس ببريد إلكتروني وكلمة مرور لا تقل عن 10 أحرف.
4. بعد ذلك يصبح إنشاء حساب المدير من شاشة الإعداد مقفلاً تلقائياً.
5. أنشئ حساب طالب تجريبي من صفحة الدخول، ثم أضف دروساً وواجبات وامتحانات من لوحة الإدارة.

## قاعدة البيانات والملفات
- قاعدة SQLite: `database/platform.sqlite` (تُنشأ تلقائياً عند التشغيل).
- الملفات المرفوعة مستقبلاً: مجلد `uploads/`.
- لا ترفع `database/platform.sqlite` أو `.env` إلى GitHub.
- لا ترفع `node_modules` إلى GitHub؛ يتم تثبيتها من `package.json`.

## النشر
على الاستضافة:
1. اضبط `NODE_ENV=production`.
2. عيّن `JWT_SECRET` إلى قيمة عشوائية طويلة وسرية.
3. استخدم استضافة تدعم Node.js وتخزيناً دائماً للملفات.
4. تأكد أن مجلد `database/` دائم الكتابة ولا يُحذف عند إعادة النشر.
5. استخدم HTTPS.

## ملاحظات مهمة
- هذه النسخة تستخدم SQLite محلية مناسبة كبداية ولمشروع صغير/متوسط على خادم واحد. عند التوسع لعدد كبير من المستخدمين أو تشغيل أكثر من نسخة سيرفر، انقل قاعدة البيانات إلى PostgreSQL.
- لا توجد بيانات تجريبية وهمية؛ يبدأ النظام بقاعدة بيانات نظيفة.
- روابط الفيديو والملفات تُضاف كرابط مباشر في هذه النسخة. رفع الملفات من داخل لوحة الإدارة يمكن إضافته لاحقاً بعد تحديد حدود الحجم ونوع الملفات ومكان التخزين.
